## 🌟 عن المشروع

**منصة شجرة النسب العائلية** هي منصة رقمية احترافية تهدف إلى:

- 📜 **توثيق الأنساب:** حفظ سلسلة النسب بدقة عبر الأجيال.
- 🌳 **عرض مرئي:** شجرة تفاعلية بأسلوب تراثي أنيق.
- 🔍 **بحث متقدم:** البحث بالاسم، الأب، أو الجيل.
- 📄 **إدارة المحتوى:** صفحات ديناميكية قابلة للتحرير.
- 👥 **إدارة المستخدمين:** 4 أدوار صلاحيات متعددة.
- 🖨️ **تصدير احترافي:** PDF بمقاسات متعددة + PNG.

**مناسبة لـ:**
- العائلات والقبائل التي تريد توثيق نسبها.
- الباحثين في علم الأنساب.
- المؤسسات التراثية والتاريخية.

### 🌳 استكشاف الشجرة

**الوصول:** من الهيدر → اضغط "المشجرة" أو اذهب إلى `/tree`

**ما يمكنك فعله:**

| الوظيفة | الطريقة |
|:---|:---|
| **تصفح الشجرة** | تمرير الماوس على الشجرة |
| **تكبير** | زر `+` أو Scroll للأعلى |
| **تصغير** | زر `-` أو Scroll للأسفل |
| **تحريك** | اسحب بالماوس |
| **البحث السريع** | اكتب في المربع أعلى اليسار |
| **البحث المتقدم** | اضغط زر "بحث متقدم" |
| **ملء الشاشة** | زر التوسيع |
| **إعادة ضبط** | زر ↺ |
| **تصدير الشجرة** | زر "تصدير" |

**ألوان الأوراق:**
- 🟢 **أخضر:** شخص حي.
- 🟡 **أصفر ذهبي:** شخص متوفى.
- 🟤 **بني:** شخص منقطع.
- ⚪ **رمادي:** غير معروف.

### 🔍 البحث المتقدم

**الوصول:** زر "بحث متقدم" أعلى اليسار في صفحة الشجرة.

**3 أنماط للبحث:**

1. **بالاسم فقط:**
   - اكتب جزءاً من الاسم → اضغط "ابحث".
   - مثال: "محمد" → يعرض كل من اسمه يحتوي "محمد".

2. **بالاسم والأب:**
   - اكتب الاسم + اسم الأب → اضغط "ابحث".
   - مثال: "محمد" + "عبدالله".

3. **بالجيل:**
   - اختر الجيل من القائمة → اضغط "ابحث".
   - مثال: "الجيل الثالث" → يعرض كل أفراد الجيل الثالث.

**النتائج:**
- تظهر في جدول منظم.
- تُضاء في الشجرة بلون ذهبي.
- اضغط على أي اسم → ينتقل إليه في الشجرة.

---

### 🖨️ تصدير الشجرة

**الوصول:** زر "تصدير" أعلى اليمين في صفحة الشجرة.

**الخطوات:**

1. اضغط "تصدير".
2. **للتخصيص:** اضغط "إعدادات العنوان والتفاصيل" لتعديل:
   - **العنوان الرئيسي:** يظهر في أعلى الصفحة.
   - **العنوان الفرعي:** اختياري.
   - **التفاصيل السفلية:** حتى 5 أسطر.
3. **اختر الصيغة:**
   - **PDF:** اختر المقاس (A4, A3, A2, A1, A0).
   - **PNG:** صورة عالية الدقة.

**المقاسات:**
| المقاس | الاستخدام |
|:---|:---|
| **A4** | طباعة على ورق عادي |
| **A3** | طباعة متوسطة |
| **A2** | لوحة متوسطة |
| **A1** | لوحة كبيرة |
| **A0** | لوحة معرض ضخمة |

> 💡 **نصيحة:** استخدم **A0** أو **A1** للطباعة على لوحة كبيرة.

### 👥 إدارة الأشخاص

**الوصول:** `/admin/people`

**إضافة شخص جديد:**

1. اضغط "إضافة شخص".
2. **املأ البيانات:**
   - **الاسم:** الاسم الأول فقط (اسم العائلة سيُبنى تلقائياً).
   - **الجنس:** ذكر أو أنثى.
   - **الحالة:** حي، متوفى، منقطع، غير معروف.
   - **الجيل:** اختر الجيل (يمكن إضافة جيل جديد).
   - **الأب:** اختر الأب من الجيل السابق.
   - **التواريخ:** الميلاد والوفاة (اختياري).
   - **ملاحظات:** أي ملاحظات إضافية.
3. اضغط "حفظ".

**إضافة جيل جديد:**

- في قائمة الجيل → اختر "✨ إضافة جيل جديد (يدوياً)".
- أدخل رقم الجيل (مثلاً: 8).
- اختر الأب من الجيل السابق.
- احفظ.

**تعديل شخص:**
- اضغط أيقونة القلم ✏️ بجانب الاسم.
- عدّل البيانات.
- احفظ.

**حذف شخص:**
- اضغط أيقونة السلة 🗑️.
- أكد الحذف.
- **ملاحظة:** لا يمكن حذف شخص لديه أبناء.

**تصفية حسب الجيل:**
- أزرار أعلى الجدول: الكل، الجيل الأول، الجيل الثاني، إلخ.

### 📄 إدارة الصفحات

**الوصول:** `/admin/pages`

**تحرير صفحة موجودة:**

1. اضغط "تحرير" على الصفحة.
2. عدّل العنوان، الرابط، أو المحتوى.
3. **المحرر يدعم:**
   - العناوين (كبير، متوسط، صغير).
   - النص (عريض، مائل، تحته خط).
   - القوائم (نقطية، مرقمة).
   - الاقتباسات.
   - المحاذاة (يمين، وسط، يسار).
   - الروابط.
   - **الصور** (زر الصورة في شريط الأدوات).
4. اضغط "حفظ".

**إضافة صفحة جديدة:**

1. اضغط "إضافة صفحة جديدة".
2. **العنوان:** مثل "أعيان القبيلة وشيوخها".
3. **الرابط (slug):** بالإنجليزية (مثل: `notables`).
4. **المحتوى:** اكتب بمحرر النص.
5. **الترتيب:** رقم أصغر = يظهر أولاً.
6. **الحالة:** منشورة / في القائمة.
7. احفظ.

> ⚠️ **ملاحظة:** الرابط (slug) يجب أن يكون بالإنجليزية لأنه يظهر في URL المتصفح.

### 👤 إدارة المستخدمين

**الوصول:** `/admin/users` (للمدير فقط)

**الأدوار الأربعة:**

| الدور | الصلاحيات |
|:---|:---|
| **مدير النظام** (SUPER_ADMIN) | كل شيء + إدارة المستخدمين |
| **مدير** (ADMIN) | كل شيء عدا إدارة SUPER_ADMIN |
| **محرر** (EDITOR) | إضافة وتعديل الأشخاص والصفحات |
| **مشاهد** (VIEWER) | قراءة فقط |

**إضافة مستخدم:**

1. اضغط "إضافة مستخدم".
2. املأ: الاسم، البريد، كلمة المرور، الدور.
3. احفظ.

**تعديل مستخدم:**
- اضغط القلم ✏️.
- عدّل البيانات.
- **لتغيير كلمة المرور:** اكتب كلمة جديدة (أو اتركها فارغة).
- احفظ.

**حذف مستخدم:**
- اضغط السلة 🗑️.
- **ملاحظة:** لا يمكنك حذف حسابك الحالي.

### ❓ الأسئلة الشائعة

**س: نسيت كلمة المرور، ماذا أفعل؟**
ج: تواصل مع المدير لإعادة تعيينها من `/admin/users`.

**س: كيف أضيف 1000 اسم دفعة واحدة؟**
ج: استخدم استيراد CSV من `/admin/settings`.

**س: الموقع بطيء عند الفتح الأول؟**
ج: طبيعي، لأن Netlify المجاني يوقف الموقع عند عدم الاستخدام (يستغرق ~30 ثانية).

**س: كيف أشارك الشجرة مع الآخرين؟**
ج: شارك رابط الموقع. للطباعة، استخدم تصدير PDF.

**س: كيف أغير شعار الموقع؟**
ج: حالياً الشعار ثابت. يمكن تطويره لاحقاً.

## 💻 التثبيت المحلي

> ⚠️ **هذا القسم للمطورين فقط.**

### 1. المتطلبات

- **Node.js:** v20 أو أحدث
- **npm:** v10 أو أحدث
- **PostgreSQL:** v15+ (أو حساب Neon/Supabase)

### 2. استنساخ المستودع

```bash
git clone https://github.com/Mohamed122-r/genealogy.git
cd genealogy
```

3. تثبيت الحزم

```bash
npm install
```

4. إعداد البيئة

```bash
cp .env.example .env
```

عدّل .env:

```env
DATABASE_URL="postgresql://user:pass@host:5432/db"
AUTH_SECRET="your-secret-min-32-chars"
NEXTAUTH_URL="http://localhost:3000"
NEXT_PUBLIC_APP_URL="http://localhost:3000"
NODE_VERSION="20"
```

5. تهيئة قاعدة البيانات

```bash
# مزامنة المخطط
npx prisma db push

# توليد Prisma Client
npx prisma generate

# إدخال البيانات الأولية
npx prisma db seed
```

6. التشغيل

```bash
npm run dev
```

افتح: http://localhost:3000

🌐 النشر على Netlify

⚠️ هذا القسم للمطورين فقط.

الخطوة 1: قاعدة بيانات Neon

1. اذهب إلى: https://neon.tech
2. سجّل بحساب GitHub.
3. اضغط "Create Project".
4. انسخ Connection String.

الخطوة 2: رفع المشروع على GitHub

```bash
git add .
git commit -m "Initial commit"
git push origin main
```

الخطوة 3: النشر على Netlify

1. اذهب إلى: https://netlify.com
2. اضغط Add new site → Import an existing project.
3. اختر GitHub → اختر مستودعك: genealogy.
4. إعدادات البناء:
   · Build command: prisma db push --accept-data-loss && prisma generate && next build
   · Publish directory: .next
   · Node version: 20

الخطوة 4: متغيرات البيئة

أضف في Netlify → Site configuration → Environment variables:

Key Value
DATABASE_URL رابط Neon
AUTH_SECRET 32 حرفاً عشوائياً
NEXTAUTH_SECRET نفس AUTH_SECRET
NEXTAUTH_URL https://genealogygenealogy.netlify.app
NEXT_PUBLIC_APP_URL https://genealogygenealogy.netlify.app
NODE_VERSION 20

الخطوة 5: النشر

· اضغط Trigger deploy → Clear cache and deploy site.

الخطوة 6: تعبئة البيانات

افتح: https://genealogygenealogy.netlify.app/api/seed-pages

· DATABASE_URL
